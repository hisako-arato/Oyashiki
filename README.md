# OYASHIKI 執事と月下の絵

お屋敷の宝を盗み出す物語。ブラウザで遊べるWebゲーム（PWA対応・オフライン可）。

執事として鷹宮家に潜入した主人公が、12月末までに隠し部屋の絵画「月下の庭」を盗み出す。

## 遊び方

- **期間**：11月〜12月の全4章。1章＝2週間。
- **執事パート（平日）**：毎朝の「朝礼」で仕事をメイドに割り振り、空いた時間で屋敷を調べる。
  - 仕事を残すと **お父様の心象** が下がり、0でクビ（GAME OVER）。
  - 人前で怪しい調査をすると **疑惑** が溜まり、100で正体が露見（GAME OVER）。
  - メイドは担当した部屋で働くので、調べたい部屋にメイドを置かないのがコツ。
- **夜（平日の22時）**：休む／自室でメイドと密談（好感度50以上。雫はいつでも）／お母様・お嬢様の部屋を訪ねる（好感度60以上。お母様は旦那様が不在の夜だけ）から1つ選ぶ。
  - 夜は「人の協力」が得られる：寝物語の手がかり、クローゼットの約束、警報の図面、模写を早める、イブの夜に2階の部屋へ招かれる（決行を2階から始められる）など。
  - 雫が来る前は、夜の2階で赤メイドに見られることがある。母娘の両方と深い仲になると、いずれ鉢合わせる（ルート3の道が開く）。
- **妹・雫（黒メイド）**：第3章の初日にメイドとしてやって来る、主人公の妹。人前では執事に厳しく、二人きりのときだけ甘える。好感度はなく、夜はいつでも密談でき、手がかりをくれる。昼に話しかけると、人目があれば他人行儀、誰もいなければ小声で助言をくれる。
  - **噂**：新しいメーターは無い。雫と夜に会うと、打ち明けていない他のメイドの好感度が −2。雫と会ってから2日以内に好感度30未満のメイドがいると、朝礼で噂になり疑惑 +5（噂で疑惑100になると「兄妹の秘密」で解雇）。
  - **打ち明ける**：協力者（好感度70）になったメイドには、夜の密談で雫とのことを打ち明けられる。打ち明けたメイドは、もう妬みも噂もしない。全員に打ち明けると、エンディングでメイドたちが兄妹を送り出す。
  - **嫉妬**：雫と会わずに他のメイドと2夜続けて会う／他のメイドが協力者になる／打ち明ける と、雫がすねる。すねている間は朝礼で重い仕事を押し付けられ、次に会った夜は情報をくれない（会えば機嫌が直る）。
  - 表現は、性的な描写はせず、大人が読めば分かる程度（暗転と翌朝の様子で示す）。
- **物語パート（週末）**：家族やメイドとの物語。選択肢で好感度や手がかりが変わる。
- **好感度70以上のメイド**は「協力者」になり、調査を見られても怪しまれない（雫は最初から味方）。
- **手帳**：集めた手がかり・いまの目標・好感度を確認できる。

## 盗み出しのルート（12月24日、クリスマス・イブの夜）

1. **一夜で持ち去る**：絵を見つけ、警報を止め、見つからない道順で運び出す。
2. **贋作とすり替える**：青メイドに模写を描いてもらい、本物はお嬢様の部屋に預ける。
3. **お父様を説得する**：お母様・お嬢様と親密になって秘密を握り、家族を崩す。

## ローカルで動かす

ES Modules と Service Worker を使うため、ファイルを直接開くのではなくHTTPサーバー経由で開く。

```sh
npx http-server -c-1 .
# http://localhost:8080 を開く
```

GitHub Pages などの静的ホスティングにそのまま置ける。

## 執事パート（3Dの屋敷）

平日の執事パートは、ローポリ3Dの鷹宮邸（使用人棟・庭・屋敷1F・屋敷2F）を主人公で歩き回って遊ぶ。

- 朝は執事の部屋のベッドで目を覚まし、共用室の席に着くと朝礼（メイドへの仕事の割り振り）が始まる。朝礼までは時計が止まっている
- 9時から18時まで。ゲーム内の1時間は約45秒。ベッドで休むか「業務を終える」で1日を終える
- 緑の印が執事の担当の仕事の場所。そこで「仕事」をすると、その時間だけ時計が進む
- 家族とメイドは本編の予定表どおりの部屋にいて、部屋の中を歩き回る（朝礼で割り振った場所で働く）。持ち場が変わると、扉・廊下・階段を通って歩いて移る（使用人は勝手口と裏階段、家族は玄関と大階段を通る。外出は正門から）
- 初日だけ、赤メイドが旦那様の「新しい決まり」の確認に付き添い、仕事・調べる・見られると疑われる仕組みを実地で教える
- イブまでの1週間は、クリスマスの飾り付け（大広間のツリー、玄関ホールのリース、2F廊下のガーランド、バラ園のイルミネーション）が毎日の仕事に入る。飾り終えた物は屋敷に残る
- 決行の夜（12月24日クリスマス・イブ、ルート1・2）も3Dの屋敷で遊ぶ。深夜1時〜夜明け5時。大広間は雫が見逃してくれるが、赤メイドがキッチン裏を、警備会社の巡回員が2階の廊下を見張り、協力者でない人に見つかると失敗（雫から巡回員の癖を聞いておける）。倉庫の梯子をバルコニーに掛けて2階へ上がれる
- 調べる・話すと20分進む。人に見られながら調べたり、私室で見つかったりすると疑惑が上がる
- 移動：矢印キー / WASD（スマホは左下のスティック）、調べる・話す・仕事：スペース / E（スマホは右下のボタン）
- 3D描画が使えない端末や、URLに `?2d` を付けたときは、ボタン式の画面で遊べる
- 3D描画に [Three.js](https://threejs.org/)（MIT License）を `vendor/` に同梱している

| ファイル | 内容 |
|---|---|
| `explore/day3d.js` | 執事パートと決行の夜の3D画面（操作・時間・人物の動き・視線・仕事・調査・会話・チュートリアル） |
| `explore/nav.js` | 人物の道順（歩ける場所の網目と A*、エリアをまたぐ道順） |
| `explore/world.js` | 間取り・家具・調べられる場所・仕事の場所（間取りを変えるときはここ） |
| `explore/engine.js` | 描画の土台・素材・人物モデル |
| `js/daylogic.js` | 仕事・調査・会話の処理（3Dとボタン式の両方で使う） |

間取りは `world.js` の `rooms`（部屋の矩形）と `doors`（開口部）から、壁・扉・床を自動で組み立てる。
