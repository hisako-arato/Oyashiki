# OYASHIKI 執事と月下の絵

お屋敷の宝を盗み出す物語。ブラウザで遊べるWebゲーム（PWA対応・オフライン可）。

執事として鷹宮家に潜入した主人公が、12月末までに隠し部屋の絵画「月下の庭」を盗み出す。

## 遊び方

**メイドの名前**：赤羽（赤メイド・34歳。年明けに2人目の子どもが生まれ、春から産休。旦那様がメイドを増やすのはその穴埋めのため）／青島（青メイド・23歳。美大で油絵を学んだが就職難で、11月1日に新卒で屋敷へ）／白井（白メイド・26歳）／黒メイド＝雫。人物照会には「赤羽（赤メイド）」のように、名前と服の色の両方を出す。

- **期間**：11月〜12月の全4章。1章＝2週間。
- **暦**：11月1日（月）に始まり、最後の週の金曜・12月24日がクリスマス・イブ。日付は「11月3日（水）」の形で出し、状況表示に「イブまで あと○日」。手帳の「予定」に、分かっている日付（麗子の誕生日、イブ、運び屋の来る25日の朝）が並ぶ。11月3日やイブの朝は、朝礼で知らせる
- **痕跡**：書斎の本棚（隠し扉）・隠し部屋の鍵（使うたびに机の引き出しから出し入れする）・資料室の敷物（床の扉）は、使ったら元に戻す。戻さないまま業務を終えると気づかれる（旦那様が在宅なら本棚 疑惑+20・鍵 +15・床の扉は錠の付け替え、不在ならメイドの噂 +8）。雫は書斎の物を、協力者のメイドは資料室の物を戻しておいてくれる。残っている間は状況表示に「⚠ 痕跡」、業務を終えるときに確認が出る
- **執事パート（平日）**：毎朝の「朝礼」で仕事をメイドに割り振り、空いた時間で屋敷を調べる。仕事は章ごとに増え（料理のほか4・7・10・10件）、12月はクリスマスの飾り付け（6種類。12月前半は1日1つ、後半は2つ）とパーティーの支度（招待状書き・クリスマス菓子・客用の食器とリネン）も加わる。 誰にも割り振っていない仕事があるまま朝礼を終えようとすると、一度だけ確認が出る。
  - 仕事を残すと **お父様の心象** が下がり、0でクビ（GAME OVER）。
  - 人前で怪しい調査をすると **疑惑** が溜まり、100で正体が露見（GAME OVER）。
  - メイドは担当した部屋で働くので、調べたい部屋にメイドを置かないのがコツ。
- **夜（平日の22時）**：休む／共用室でメイドに声をかける（好感度35以上。一杯飲みながら話す）／自室に雫を呼ぶ（いつでも）／お母様・お嬢様の部屋を訪ねる（好感度60以上。お母様は旦那様が不在の夜だけ）から1つ選ぶ。選べるようになるまで選択肢は出さず、休む以外に選べることが無い夜は、夜の画面を出さずに休む。新しく選べるようになった相手には「NEW」が付く。
  - メイドとの夜は「世間話」か、主人公から話題を振る。話題は、主人公が調べて分かったことから生まれる（手がかり → 質問 → 答え）。例：赤羽に旦那様のことを尋ねると、前のメイドが濡れ衣で辞めさせられた過去を話し、倉庫の伝票を見つけた後なら額縁の荷物のことを聞ける
  - 昼の会話でも、手がかりにつながる話は主人公が先に尋ね、相手が答える
  - 物語の手がかりを聞き出せそうな相手には、夜の選択肢に「◆ 聞ける話がありそうだ」と出る（その夜の場面を試しに流して、新しい手がかりが手に入る選び方があるかで決める）
  - 執事の心の内：白・お母様・お嬢様とは、情報を聞き出すために会う（聞き出すことが無くなっても足が向く）。赤・青とは、一緒にいて楽しく、本来の目的を忘れそうになる
  - 夜の場面には、場所と時刻の札（「23:10　屋敷 2F　お嬢様の部屋」など）が出る。夜は背景がランプの灯りになる
  - **お母様・お嬢様との夜**：表現の線引きは「キス・抱擁・髪や指に触れる・ボタンを1つ外す・ガウンの紐がほどける・ベッドに腰を下ろす」まで。その先は暗転（画面がゆっくり黒くなる）し、夜明け前や翌朝の様子で示す。性的な描写はしない
    - 夜を重ねるごとに場面が変わり、寝物語で情報を聞き出せる。お嬢様：赤い本／大学を辞めた秘密／子どもの頃に見た資料室の床の下（地下のヒントの1つ）／預かり／イブの夜、お父様は朝まで帰らない。お母様：麗子／番号は麗子の誕生日／夜中に来る絵の業者／オークション会社の手紙
    - 翌朝は「夜明け前、○○からそっと自室に戻った」と出て、お母様・お嬢様・赤羽の反応が変わる。主人公の葛藤（絵のために利用している）も描く
    - 深い仲になると、勉強の手伝い・お供の結果の文が関係を示唆するものに変わる。お母様が在宅の日の勉強の時間は、隣の主寝室に聞かれることがあり（疑惑 +3）
    - エンディングで屋敷を去るとき、深い仲だった相手の反応が出る（母娘の両方と深い仲になっても、互いの関係は最後まで知られない）
- **仕事を待つ**：相手や時刻の都合で今はできない仕事（お嬢様の勉強の手伝いは13時から）は、緑の印で「○時まで待つ」を選べる。勉強の手伝いの日は、お嬢様が13時に自室へ戻る
  - 夜は「人の協力」が得られる：寝物語の手がかり、クローゼットの約束、警報の図面、模写を早めるなど。
  - 雫が来る前は、夜の2階で赤羽に見られることがある。
- **白井（お父様の目）**：第2章の初日に、お父様が自分の会社から連れてくる予定外の新人（26歳。会社の帳簿で記録のない収蔵庫の電気工事に気づき、屋敷へ飛ばされた）。週末ごとにお父様へ屋敷の様子を報告する。
  - 白に見られると「報告の種」がたまる（調べ物 +5、書斎・私室・地下から上がるところ +10、雫を夜に呼んだ夜 +3）。週末の報告で、好感度40未満なら全部、40〜59なら半分が疑惑になり、60以上なら伏せてくれる
  - 白の過去を聞き（夜の話題・好感度50・謎の系統の話の後）、地下の保管庫の話をすると寝返る。寝返るか協力者（好感度70）になると、嘘の報告で疑惑 −5。寝返っていれば、好感度70未満でもイブの警報を頼める
  - 味方にしないまま報告で上がった疑惑が合計20以上になると、最終章の初日にお父様がイブの夜の巡回を厳しくする（巡回員が西の端で立ち止まる時間が短い）
  - 「月と取引」で帳簿を送るとき、白が寝返っていれば会社の支払いの記録も添えてくれる
- **妹・雫（黒メイド）**：第3章の初日にメイドとしてやって来る、主人公の妹。人前では執事に厳しく、二人きりのときだけ甘える。好感度は100のまま。夜は自室に呼べ、手がかりをくれる。昼に話しかけると、人目があれば他人行儀、誰もいなければ小声で助言をくれる。
  - **噂**：新しいメーターは無い。雫と夜に会うと、打ち明けていない他のメイドの好感度が −2。雫と会ってから2日以内に好感度30未満のメイドがいると、朝礼で噂になり疑惑 +5（噂で疑惑100になると「兄妹の秘密」で解雇）。 共用室でメイドと飲むだけなら、噂にはならない。
  - **打ち明ける**：協力者（好感度70）になったメイドには、共用室で飲む夜に、雫とのことを打ち明けられる。打ち明けたメイドは、もう妬みも噂もしない。全員に打ち明けると、エンディングでメイドたちが兄妹を送り出す。
  - **嫉妬**：雫を呼ばずに他のメイドと共用室で飲む夜や、主寝室・お嬢様の部屋を訪ねる夜が3回続く／他のメイドが協力者になる／打ち明ける と、雫がすねる。すねている間は朝礼で重い仕事を押し付けられ、次に会った夜は情報をくれない（会えば機嫌が直る）。
  - 表現は、性的な描写はせず、大人が読めば分かる程度（暗転と翌朝の様子で示す）。
- **物語パート（週末）**：家族やメイドとの物語。選択肢で好感度や手がかりが変わる。
- **好感度70以上のメイド**は「協力者」になり、調査を見られても怪しまれない（雫は最初から味方）。
- **手帳**：集めた手がかり・いまの目標・好感度を確認できる。

## 冒頭のイブの一場面

「はじめから」を選ぶと、最初にイブの夜の一場面を見せる（仮面舞踏会の大広間 → 0時の鐘 → 停電 → 額縁に伸びる白い手袋）。タップで進み、「――その、2か月前。」からプロローグが始まる。右上の「スキップ」で飛ばせる。物語のあちこちに、イブの夜につながる伏線を置いている（仮面舞踏会の客、嵐の夜の停電、仕出し屋で働く雫の知り合い、大広間に飾られる絵、仮面の絵付け、麗子の来訪など）。

## 地下室

- 資料室の床下に、表向きは古いワイン貯蔵庫の地下室がある。最初は見つかっていない
- 手がかり（庭の古井戸の風／白井の「どこにもつながらない配電の系統」／赤羽の「旦那様はワインを取りに行くと戻ってこない」／資料室の設計図の階段の記号）のうち2つを集めると、12月以降に資料室の敷物の下の床の扉が見つかる
- 降りるには、セラーの鍵（旦那様が不在の日の食料庫、または雫から）と、倉庫の工具棚の懐中電灯が要る
- ワイン棚の一つが隠し扉で、奥の保管庫には盗品の名画、仕入れ帳、オークション会社との手紙、25日の発送伝票がある。お父様が裏のルートで名画を買い集め、来歴を偽って売りさばこうとしている証拠
- 保管庫の奥の搬入路は庭の古井戸へ続く。鉄格子のボルトをバールで外せば、古井戸から地下へ出入りできる
- **見つかったら罰**：地下にいる時間そのものに罰はない（ほかの探索と同じく時間が経つだけ）。家の者に無断で地下に入っているところを見られると罰がある
  - 床の扉や古井戸から上がるとき、上に人がいれば「足音が聞こえる」と分かり、待つか上がるかを選べる。上がった瞬間を見られたら言い訳を選ぶ（疑惑 +5〜15）。協力者・雫・打ち明けたメイドは見逃してくれる
  - 旦那様が在宅の日は、17時台に晩酌のワインを取りに降りてくる（朝礼の予定に出る）。扉の開く音から8秒以内に、保管庫の奥か搬入路に隠れればやり過ごせる。貯蔵庫で見つかると疑惑 +20・心象 −10、セラーの鍵を取り上げられる（雫に新しい合鍵を頼める）
  - 最終章は、旦那様が発送前の荷物を確かめに保管庫まで入ってくる。隠れられるのは搬入路だけ。保管庫で見つかると疑惑 +40・心象 −20
- 仕入れ帳の写真があれば、どのエンディングでも、最後に仕入れ帳の写真を美術館に匿名で送るかどうかを選べる

## イブの仮面舞踏会（12月24日 19:00〜0:30）

イブの日は、業務報告の後に仮面舞踏会になる（3Dの屋敷の1階。音楽は「美しく青きドナウ」）。台詞と出来事は `js/ball.js`、動きは `explore/day3d.js` の `startBall`。
- **19:00 開宴**：旦那様が「月下の庭」を大広間の壁に飾って披露し、お嬢様を「美術史を学ぶ娘」と紹介する
- **19:30〜 配膳**：キッチンのワゴンで、銀のお盆にシャンパングラスを4本受け取り、頭に「！シャンパン」が出た客へ1本ずつ配る（同時に待つ客は最大4人）。4本配り終えたら、キッチンへ戻って次の4本を受け取る。渡した客からは、伏線につながる話が一つずつ聞こえる（絵の見納め・担当者・嵐の夜の停電・会社の裏金・お嬢様の大学・仕出し屋のバン・地下の「ほかの物」・麗子の連れ）。待たせすぎると客が離れる。閉宴のとき、配ったグラスと待たせた客で旦那様の心象が上下する（最大±6）
- **21:00 麗子の登場**：深紅の仮面で、若い男（お母様が贈り物をしていた相手）を連れて来る。お母様は執事に目もくれず、麗子に嫉妬する
- **22:00 ワルツ**：相手を選ぶ（お嬢様＝深い仲か好感度70以上／青＝協力者のとき／仕事に徹する）。雫とは、いないことに気づいて探しに行ったときだけ踊る（下記）。二人で揺れて回りながらボックスステップを踏み、小節ごとに縮む輪が的に重なった瞬間にタップする。点数で相手の反応と好感度が変わる
- **0:00 仮面外し**：鐘に合わせて、全員が仮面を右手へ下ろす
- **0:30 閉宴**：絵は隠し部屋に戻され、決行の夜へ続く
- 配膳・ダンス・暗闇の長い説明は、初めてのときだけ出す（端末に覚える。2回目からは短い案内だけ）
- 舞踏会の間は、誰に見られても怪しまれない。人に話しかけられる（赤羽は担当者を「夜中に来る車の人」と気づく、仕出し屋は雫の知人として裏のバンのことを話す、など）
- 舞踏会が終わると、麗子・担当者・仕出し屋・お嬢様のドレス・一般客の VRM を手放す（端末のメモリを空ける）
- **軽い描き方**（人数は減らさない）：屋敷の中の人物は、いつも揺れもの（髪・スカート）の計算を止めて形を固定し、アニメ調の輪郭線を省き、影を落とさずに足元へ丸い影を置く（`explore/vrm.js` の `attachVRM`。会話の顔と人物照会では、揺れも輪郭線も元のまま）。舞踏会の間は、家具や建物の影も落とさない（`setCrowd`）。仮面は材質ごとに1つの部品にまとめてある。遠い客の動きは4フレームに1回。会話の顔は1秒に15回、黙っている間は描かない（顔を描くときだけ輪郭線を戻す）。同じ23人を描く比べ（ソフトウェア描画）で、1フレーム 693ms → 86ms、動きの計算 19ms → 2ms
- 会話の顔は、本当に描けたときだけ顔アイコンと入れ替える（描けなかったときは顔アイコンのまま）
- **22時（お嬢様と踊れるとき）**：まずお嬢様が誘いに来る（「お嬢様とダンスする」／「仕事に戻る」）。踊ると決めたところで雫がいないことに気づき、「この日のために、ダンスだけは練習したんだから」と話すお嬢様の前で、もう一度「お嬢様とダンスする」／「雫を探しに行く」を選ぶ
- **お母様**：執事は若い遊び相手にすぎず、イブの夜に誘うことはない（前任の執事も若手人気俳優に似ていて、お母様とよく出かけていたと、第1章の週末に赤羽が話す）。舞踏会では、深い仲でも執事に目もくれない
- **雫と踊った夜**：閉宴の後、雫が執事の部屋に来て「いよいよだね。……頑張ろうね」「たまには昔みたいに、お兄ちゃんの部屋で寝たいな」。執事が断る前に、雫はベッドで眠ってしまい、執事は床で仮眠をとる。決行の夜は、床で目を覚まして始まる（雫は眠っているので、大広間は代わりに、眠れない旦那様がゆっくり歩き回る。見つかれば失敗）
- **お嬢様と踊った後**：「このあと、私の部屋に来て」と誘われる（前の夜に約束していれば、その約束を持ち出す）。**行く**：閉宴の後、お嬢様の部屋で夜を過ごし（ベッドに腰を下ろすまで書いて暗転）、決行の夜はお嬢様の部屋から**1時30分**に始まる（寝付くのを待つぶん30分短い）。ベッドで眠るお嬢様に「布団を掛け直す」と「（……ごめん）」の一言が出て、ENDING 1 の余韻の一言が変わる。ルート2なら、25日の朝もお嬢様の部屋で目を覚ます。**行かない**：お嬢様がバルコニーの鍵を開けておいてくれる（梯子で2階へ上がれる。勝手口と古井戸も使える）。お嬢様の部屋から始まるのは、この誘いに応じたときだけ
- **22時（お嬢様と踊れないとき）**：雫と再会していれば、大広間に雫がいないことに気づく。「雫を探す」を選ぶと、屋敷を歩いて探し（その間は時計が止まる）、2階のバルコニーで寂しそうな雫を見つける（ここで「別れのワルツ」）。遊園地の思い出の話の後、手を取ってワルツへ。「仕事に戻る」を選ぶと、ほかの相手（お嬢様・青・仕事に徹する）から選ぶ

## 伏線と回想カード

物語のあちこちの手がかりは、イブの一日で回収される（`js/recall.js` の `FORESHADOW`。14個）。回収の瞬間に、画面の上に「回想カード」が数秒出る（手がかりを得た日付・その一文・どう回収されたか）。手がかりを得た日は `s.clueDay` に覚える。回収した伏線は端末に覚えておき（遊び直しても残る）、クリアした後は手帳に「伏線」のページが増える（見逃した物は「？？？」）。
例：麗子の誕生日 → 隠し部屋の鍵の番号／書斎の油絵具の匂い → イブの昼、旦那様が自ら絵を掛ける／嵐の夜の停電 → 0時の停電劇／母の日記の蔵印 → キャンバスの裏／前のメイドの濡れ衣 → 取り調べで赤が言い返す、など

## 盗み出しのルート（12月24日、クリスマス・イブの夜）

どちらのルートも、3Dの屋敷で主人公を操作して盗み出す（このゲームのいちばんの見せ場）。

1. **一夜で持ち去る**：絵を見つけ、警報を止め、見つからない道順で運び出す。絵を抱えたまま梯子と古井戸は使えない（額縁が擦れてキャンバスに傷がつく）。屋敷の中を歩いて1階へ降り、勝手口から庭へ出て、バラ園の奥の庭師の通用口（調べるか赤羽から聞く。知らないとこのルートは選べない）から抜け出す。玄関は絵とは別の警報が付いていて使えず、正門は閂と巡回員で出られない。→ ENDING 1
2. **贋作とすり替える**（絵を見つけた後、好感度60以上の青に昼か夜に模写を頼む。完成まで5日。手帳の目標に、残り日数と間に合わないときの知らせが出る。作戦の画面には、足りないものが出る）：イブの日の13時、旦那様が自ら「月下の庭」を大広間の壁に掛ける。人の目（協力者は数えない）が無いときに、青の模写とすり替え、本物を2階のお嬢様の部屋のクローゼットへ運んで隠す（運んでいる間に見られると、一人につき疑惑+20。18時を過ぎると慌てて押し込み、疑惑+15）。夜の舞踏会では、旦那様が偽物を誇らしげに見せびらかすが、誰も気づかない。決行の夜は何もせず、25日の朝、運び屋が偽物を梱包している間に、本物を洗濯かごに隠して運び出す。仕出し屋（雫の知人）を知っていれば、勝手口の外の白いバンの空の料理箱に紛れ込ませ、知らなければ使用人棟の自室へ（1階の廊下に旦那様、2階の廊下に木箱を運ぶ警備員。運んでいるところを見られるか、10時を過ぎると失敗）。すり替えた後は、ルート1は選べない（隠し部屋にあるのは偽物）。→ ENDING 2
3. **停電劇（真の結末）**：4人のメイド全員が協力者で、雫とのことを全員に打ち明けてあると、12月23日の夜に共用室で決起会を開ける。そこで「予告状を出す」を選ぶと、雫が翌朝、書斎の机に予告状（「仮面が外れる時刻に、月をいただく」）を置く。旦那様は意地になり、絵を大広間に飾ったまま巡回員を増やす。舞踏会の0時、仮面外しの瞬間に白が屋敷の電気を落とし、暗闇が90秒続く（会話の間は止まる）。壁の額縁からキャンバスを外し（青が作った麗子か担当者の仮面の切れ端を落としておける）、料理の昇降機・仕出し屋の配膳車・応接室のピアノのどれかに隠して、明かりが戻る前に大広間の真ん中へ戻る。停電の間は、増やされた巡回員が懐中電灯で大広間を回り、キャンバスを抱えているところを照らされると失敗（BAD END「明かりの下で」）。明かりが戻ると取り調べになる：隠し場所（配膳車は仕出し屋と話してあれば安全）・元の場所に戻れたか・仮面の切れ端（麗子ならお母様が喜んで責め、担当者なら旦那様が疑う）・停電のときの居場所の答え方（踊った相手やメイドが証言する）・白と雫の証言で疑いが決まる。旦那様が赤に罪を着せようとすると、赤が初めて言い返す。疑いが4以上で見抜かれる（BAD END「仮面の下の素顔」）。逃げ切れば、明け方に仕出し屋（雫の知人）へ絵を託し、5人は屋敷で働き続ける。→ ENDING 3（称号は、明かりが戻るまでの残り時間と、取り調べの疑いで決まる）

- 決行の夜は、2階の廊下の巡回員（ときどき途中で引き返す）に加えて、もう一人の巡回員が前庭から正門の前までを回り、バルコニーを見上げる
- 見せ場では大きな文字（潜入・奪取・脱出）が出る。一夜で持ち去るときは、空の額縁にカードを残すか選べる
- 盗み出せたときは、エンディングの画面に手際（所要時間・ニアミスの回数）と称号（月下の怪盗／影の執事／危うい綱渡り）が出る

夜は倉庫から資料室への扉に鍵が掛かる。屋敷に入るには、勝手口（赤羽の前を通る）、地下の搬入路、梯子とバルコニー、舞踏会の後にお嬢様の部屋へ行ったときはそこから、のいずれか。出るときは、絵を傷めない勝手口だけ。

## 執事パート（3Dの屋敷）

平日の執事パートは、ローポリ3Dの鷹宮邸（使用人棟・庭・屋敷1F・屋敷2F）を主人公で歩き回って遊ぶ。

- 朝は執事の部屋のベッドで目を覚まし、共用室の席に着くと朝礼（メイドへの仕事の割り振り）が始まる。朝礼までは時計が止まっている
- 9時から18時まで。ゲーム内の1時間は約45秒。ベッドで休むか「業務を終える」で1日を終える
- 緑の印が執事の担当の仕事の場所。そこで「仕事」をすると、その時間だけ時計が進む
- 家族とメイドは本編の予定表どおりの部屋にいて、部屋の中を歩き回る（朝礼で割り振った場所で働く）。持ち場が変わると、扉・廊下・階段を通って歩いて移る（使用人は勝手口と裏階段、家族は玄関と大階段を通る。外出は正門から）
- 初日（11月1日）は新人の青島が来る日。執事が青に仕事を教えながら、仕事・調べる・見られると疑われる仕組みを実地で覚える（メイドが二人になったので、この日から執事が朝礼で仕事を割り振る）
- イブまでの1週間は、クリスマスの飾り付け（大広間のツリー、玄関ホールのリース、2F廊下のガーランド、バラ園のイルミネーション）が毎日の仕事に入る。飾り終えた物は屋敷に残る
- 決行の夜（12月24日クリスマス・イブ、ルート1・2）も3Dの屋敷で遊ぶ。深夜1時〜夜明け5時。大広間は雫が見逃してくれるが、赤羽がキッチン裏を、警備会社の巡回員が2階の廊下を見張り、協力者でない人に見つかると失敗（雫から巡回員の癖を聞いておける）。赤羽は1時半ごろに休み、勝手口の前が空く。外の巡回員は前庭・正門の前・西の芝生（古井戸と通用口の手前）を回る。倉庫の梯子をバルコニーに掛けて2階へ上がれる（絵を持って降りるのには使えない）
- 調べる・話すと20分進む。人に見られながら調べたり、私室で見つかったりすると疑惑が上がる
- 移動：画面のどこでも、指を置いてなぞるとその向きへ歩く（指を置いた所に輪が出る）。PC は矢印キー / WASD
- 決定（調べる・話す・仕事・移動）と会話の「次へ」：軽くタップ（PC はスペース / E）。決定できる物には ▶ が付く
- 朝礼を済ませるまでは、使用人棟から出られない
- 好感度や疑惑の変化は、台詞の下に色付きの札で出す（好感度が上がると赤い ♥、下がると青、疑惑は紫）
- 屋敷には、ストーリーに関係のない小物も多く置いてあり、調べると一言ずつ説明が出る。手帳に「屋敷で調べた物」の数が場所ごと（使用人棟・庭・屋敷 1F・屋敷 2F・地下）に出て、場所をすべて調べると★が付く
- お母様のお供は、お母様の頭の上に目印が出る。話しかけると「お供する」を選べる
- 3D描画（WebGL）が使えない端末は非対応（タイトルでそう知らせる）
- 動作確認用の切り替え：URLに `?2d` を付けるとボタン式の画面、`?test` を付けるとキャラクターのモデルを読み込まない（人物は見えないまま動く）
- 3D描画に [Three.js](https://threejs.org/)、VRM の読み込みに [three-vrm](https://github.com/pixiv/three-vrm)（どちらも MIT License）を `vendor/` に同梱している
- 人物はすべて VRM で表示する。ゲームを始める前に全員を読み込む（初回は約42MBをダウンロード、2回目からは端末に保存した分を使う）
- 名前の札・人物一覧・朝礼のメイド欄・好感度・会話の顔（VRM が映るまで）には、VRM から作った顔アイコン（`assets/faces/`）を出す
- 画面の外にいる人は動きの計算と描画を止め、遠くの人は計算を2フレームに1回にする（見た目は変わらない）

| ファイル | 内容 |

| `explore/day3d.js` | 執事パートと決行の夜の3D画面（操作・時間・人物の動き・視線・仕事・調査・会話・チュートリアル） |

## バージョンと更新

- タイトル画面の下に、いま遊んでいるバージョンを表示する
- タイトル画面の「設定」で、公開ページの最新版と比べ、「最新版に更新する」で読み込み直せる（セーブデータと VRM は残す）
- セーブは5つの枠。毎朝その枠に自動で保存する。タイトルの「つづきから」「はじめから」で枠を選び、コピー・削除もできる（以前のセーブは枠1に移す）
- クリアしてもセーブは消さない（枠に「クリア済み（ENDING n）」と記す）。消すのはプレイヤーが手で
- タイトルの「設定」で、セーブを1行の文字列に書き出し、別の枠や端末に読み込める
- 新しい版で初めて起動したときは「バージョン ○○ に更新しました」と一度だけ知らせる
- **イブの朝の自動セーブ**：12月24日の朝は、枠ごとの専用の場所にも保存する。結末の画面に「イブの朝からやり直す」が出る
- **エンディング一覧**：一度でも結末を見ると、タイトルに「エンディング一覧」が出る。見た結末は題名、まだの結末は「？？？」と条件のヒント（端末に覚える）
- **既読スキップ**：一度読んだ台詞には「既読スキップ ▶▶」が出る。押すと、まだ読んでいない台詞か選択肢まで早送りする（読んだ台詞は端末に覚える）
- **24日のテストプレイ**（開発用・通常のプレイには出さない）：タイトル画面のバージョン表示を3秒以内に5回タップすると出る。「24日の朝（イブの昼）から」か「24日の深夜（作戦を選ぶ画面）から」を選び、条件のひな形（ENDING 1・2・3 の条件／何もそろっていない）で始める。お嬢様・お母様との関係も、それぞれ「ふつう（好感度30）／親しい（70。秘密を打ち明けられている）／深い仲（85。夜を重ねた仲・イブの夜に部屋へ招かれている）」から選べ。どのセーブ枠にも保存せず、画面の上に「テストプレイ」と出る。結末の画面から、同じ条件でやり直すか別の条件を選べる（`js/evetest.js`）
- main に入れるときは、`python3 tools/bump_version.py 1.16` でバージョンを上げる（`js/version.js`・`version.json`・`sw.js` のキャッシュ名をそろえて書き換える）

## 音楽

曲は著作権の切れた作品の、自由に使える演奏。`assets/music/` に、スマホ向けに音量をそろえて 96kbps の AAC（.m4a）にしたものを置く（元のファイルは `assets/` に置いたまま）。

| 場面 | 曲 |
|---|---|
| タイトル・プロローグ・週末・エンディング（クリア） | ドビュッシー「月の光」 |
| 昼の執事パート | 弦楽四重奏曲 第1楽章 |
| 夜（22時） | なし |
| 決行の夜 | ベートーヴェン「月光」第3楽章 |
| 仮面舞踏会・お嬢様とのダンス（これから作る） | シュトラウス2世「美しく青きドナウ」 |
| 雫とのダンス（これから作る） | ショパン「別れのワルツ」 |

- 場面が変わると、1.5秒かけて曲を切り替える。BAD END では音楽を止める
- スマホは最初のタップから鳴らし始める。別のアプリに切り替えると止まる
- 音量は「設定」で変えられる（音楽と効果音を別々に。0 で鳴らさない）。iPhone では消音モードのときは鳴らない
- 効果音は録音ファイルを使わず、その場で合成する（`js/music.js` の `SFX`）：足音・扉・警報（見つかったとき）・停電・0時の鐘・食器（料理を出したとき）・ダンスのタップ
- 曲は初めて流すときに丸ごと読み込んで端末に保存する（オフラインでも鳴る）。曲を差し替えるときは `js/music.js` のキャッシュ名を上げる
- 曲の変換：`ffmpeg -i 元.mp3 -af loudnorm=I=-20:TP=-2:LRA=11 -c:a aac -b:a 96k -movflags +faststart assets/music/名前.m4a`

## メニュー

画面右上の「メニュー」から開く。
- **手帳**：いまの目標・手がかり・好感度
- **人物**：登場人物の紹介と、物語で分かったこと。タップすると VRM を3Dで眺められる（1本指で上下左右に360度回す・画面の幅で半回転、勢いよく離すと少し惰性で回る。回す中心は見ている所なので逆さにしても画面から外れない／「向き」のスライダーと「正面・右・背面・左」ボタンでも横に回せる（立った姿勢に戻る）／2本指でつまんでズーム・寄ると顔へ／2本指で上下になぞると見る高さが変わる／ダブルタップで元に戻す／表情とポーズの切り替え）。物語で明かされるまでは伏せる
- **ストーリー**：たどり着いた章までのあらすじ
- **設定**：音楽の音量、キャラクターを端末に保存、タイトルへ戻る

## VRM（キャラクターの3Dモデル）

会話では、話し手の VRM を胸から上で映す（物語パートの会話画面と、3Dの屋敷のメッセージ欄）。表情は台詞から自動で決める（`js/faces.js`）。決まった表情にしたい行は、シナリオの3つ目の要素で指定できる：`['mother', '「……」', 'sad']`（neutral / happy / angry / sad / surprised / relaxed）。話している間は口が動き、心の声（…）では動かない。屋敷の中の VRM も、話している間はその表情になる。

| フォルダ | 内容 |
|---|---|
| `assets/vrm/*.vrm` | 元のファイル（VRoid Studio で作成。ゲームでは読み込まない） |
| `assets/vrm/black2.vrm` | 雫の部屋着。二人きりの会話の顔（来た日の夜を除く）と、人物照会の「服装：部屋着」で使う |
| `assets/vrm/black3.vrm` | 雫の私服。屋敷を出た後の結末の会話の顔と、人物照会の「服装：私服」で使う |
| `assets/vrm/butler2.vrm` | 執事の決行の服。イブの夜の屋敷（3D）と、その夜の会話の顔・その夜に終わる結末で使う |
| `assets/vrm/mother2.vrm` | お母様の部屋着。主寝室の夜の会話の顔と、人物照会（深い仲になった後）で使う |
| `assets/vrm/daughter2.vrm` | お嬢様の部屋着。お嬢様の部屋の夜の会話の顔と、人物照会（深い仲になった後）で使う |
| `assets/vrm/daughter3.vrm` | お嬢様のドレス（イブの仮面舞踏会。これから組み込む） |
| `assets/vrm/reiko.vrm` | 麗子（舞踏会の客。これから組み込む） |
| `assets/vrm/dealer.vrm` | オークション会社の担当者（舞踏会の客。蝶ネクタイを消し、ネクタイをベストの中に納めた：`tools/vrm_fix_tie.py`） |
| `assets/vrm/caterer.vrm` | 仕出し屋（雫の知人。3つの結末すべてで絵を外へ運ぶ。これから組み込む） |
| `assets/vrm/guest/guest_*.vrm` | 舞踏会の一般客。担当者・麗子・お嬢様のドレスから `tools/vrm_guest.py` で色を変え、画像256px・表情と揺れものなしにした軽い版（2〜3MB） |
| `assets/vrm/view/` | 人物照会用（テクスチャ1024px、表情に使わない顔のモーフを除去）。約6〜8MB |
| `assets/vrm/lite/` | 屋敷の中用（テクスチャ512px、モーフの法線も除去）。約4MB |

元のファイルを差し替えたら、次のコマンドで作り直す（要 Python と Pillow）。
```
for id in butler butler2 father mother mother2 daughter daughter2 daughter3 red blue white black black2 black3 guard reiko dealer caterer; do
  python3 tools/vrm_lite.py assets/vrm/$id.vrm assets/vrm/view/$id.vrm --tex 1024
  python3 tools/vrm_lite.py assets/vrm/$id.vrm assets/vrm/lite/$id.vrm --tex 512 --no-morph-normals
done
```
VRM は、一度読み込むとオフライン用に端末へ保存する。設定の「キャラクターを端末に保存」で、屋敷・会話用（約88MB。舞踏会の一般客を含む）と人物照会用（約130MB）を先に落としておける。

舞踏会の夜だけ、麗子・担当者・仕出し屋・お嬢様のドレス・一般客4体を読み込む（`js/state.js` の `BALL_CAST`）。一般客は、4体を形と画像を共有したまま複製して大勢に見せる（`explore/guests.js`。骨だけを複製ごとに持ち、毎フレーム元の VRM に姿勢をつけて写す）。

**仮面**：舞踏会の仮面はゲームの中で作る（`explore/masks.js`）。ベネチア風の半仮面で、人物ごとに色・縁取り・飾り（羽根・宝石・レース）が違う。頭の骨に付け、顔の正面から光線を当てて顔の表面に沿わせる。0時の仮面外しでは、仮面を右手まで下ろして持たせる。床に落ちた仮面の切れ端も作れる。

顔アイコンは人物照会用の VRM から撮って作る。VRM を入れ替えたり服を変えたりしたら作り直す：

```
python3 -m http.server 8080 &
NODE_PATH=$(npm root -g) node tools/face_icons.mjs
```

作り直したときは `sw.js` と `js/vrmstore.js` の `VRM_CACHE` の名前を変えると、新しいファイルが読み込まれる（今は `oyashiki-vrm-v2`）。
