# イブの夜の大型アップデート：決定事項（設計メモ）

物語のすべてを「12月24日、クリスマス・イブの仮面舞踏会の一夜」の伏線にする。どの結末でも、イブの一日の中で伏線を回収する。
この文書は、決まったことの控え。実装はここに沿って、1つ終わるごとに確認しながら進める。

## 日付とイブ
- 11月1日を月曜とし、週の月〜金と週末で数える。最後の週の金曜が 12/24＝イブ。
- イブの昼は舞踏会の準備、夜は仮面舞踏会。決行はイブ当日（結末ごとに時間が違う）。25日（土）の朝がルート2の持ち出し。
- 状況表示に「イブまで あと○日」。手帳に予定（11/3 麗子の誕生日、12/24 イブ、12/25 朝7時 運び屋）。誕生日の当日は朝礼で知らせる。

## イブの一日（3つの結末で共通）
- イブの日だけ、お父様が「月下の庭」を隠し部屋から大広間へ移して飾る（裏の顧客に見せびらかすため）。
- 仮面舞踏会。主人公とメイドたちも配膳に出る（3Dの操作）。客の会話から情報を拾える。
- 流れ：19:00 開宴と乾杯（絵の披露）→ 19:30 配膳 → 21:00 麗子の登場 → 22:00 ダンス → 0:00 仮面を外す儀式 → 0:30 閉宴。
- 麗子が来る。お母様は主人公には目もくれず（深い仲でも同じ）、麗子に嫉妬する。お母様の「若い男」は麗子の連れとして来る。
- オークション会社の担当者が来る（赤が「夜中に来る車の人」と気づく）。客は盗品を買い集める常連たち。
- 仕出し屋＝雫の知人。3つの結末すべてで、絵を外へ運ぶ受け手になる（第3章のうちに雫が「知り合いが仕出し屋で働いてる」と言っておく）。
- 冒頭に、イブの一場面（暗い大広間・0時の仮面外し・額縁に伸びる手袋の手）を数秒見せてから「――その2か月前」と始める。

## ダンス（3D）
- 相手：お嬢様（深い仲か好感度70以上。大広間の真ん中で）／雫（再会後いつでも。2階のバルコニーで二人きり、メイド服のまま。「私も一度、こういう場所で踊ってみたかったの」）／仕事に徹する（心象が少し上がる）／おまけの青（協力者。足を踏みまくる）。
- お嬢様と踊ると、バルコニーから見下ろす雫の寂しそうな一言。断って雫と踊ると、お嬢様が少しすねる。
- 動きは手作り（ワルツの揺れと回転・四角のステップ）。VRMA が見つかれば差し替え。3拍子に合わせて輪が縮み、ちょうどでタップする遊び。合い方で相手の反応・好感度・決行前の一言が変わる。
- ENDING 3 では、停電の瞬間に踊っていた相手がアリバイになる（お嬢様：「執事さんは、ずっと私と踊っていました」）。

## 3つの結末
- **ENDING 1　一夜で持ち去る**：閉宴後、絵が隠し部屋に戻された深夜に盗む。巡回員2人（2階の廊下・外周）。絵を抱えたまま梯子と井戸は使えない（キャンバスに傷がつく）ので、屋敷の中を1階へ降り、勝手口から出て裏庭の通用口へ（正門は閂と巡回員、玄関は別の警報で使えない。赤は1時半に休む）。裏道で仕出し屋の車が待つ。必要な仲間：白（警報）。
- **ENDING 2　すり替え**：舞踏会の前の準備の昼に、大広間で模写とすり替え、本物をお嬢様のクローゼットへ（メイドたちが盾、雫がお父様を足止め）。舞踏会でお父様が偽物を自慢するが誰も気づかない。25日の朝、運び屋と入れ違いに本物を運び出し、仕出し屋の空の料理箱に紛れ込ませる。必要な仲間：青（模写）、お嬢様（預け先）。
- **ENDING 3　停電劇（4人全員が協力者のときだけ・真の結末）**：前日（12/23）に予告状を出す（「仮面が外れる時刻に、月をいただく」）。お父様は意地になり、警備を増やして絵を大広間に飾ったままにする。0時の仮面外しの瞬間に白が屋敷の電気を落とす。暗闇（実時間90秒ほど）を操作して絵を外し、隠す。客は小さな灯りの影として映す。現場に客の仮面の切れ端を落としておける。明かりが戻ると取り調べ（選択肢の心理戦）。メイドたちの証言で潔白を証明し、疑いを外へ向ける（麗子に向けば、お母様が喜んで責める）。お父様がまたメイドに罪を着せようとし、赤が初めて言い返す。明け方、仕出し屋（雫の知人）に絵を託す。主人公とメイドたちは翌日から何事もなかったように働く（屋敷を去らない唯一の結末）。後日談：「年が明けても、5人は鷹宮家で働いていた。ただ、大広間の壁だけが空いていた」。
- 母の日記の蔵印は「キャンバスの裏」にあることにする（キャンバスだけ外しても証拠が残る）。

## ENDING 3 の細部（おすすめで決定）
- 予告状は、前日に雫が書斎の机に置く（掃除の担当なので自然）。
- 停電中に絵を隠す場所は選べる：料理の昇降機／仕出し屋の配膳車／大広間のピアノの中。それぞれ取り調べでの危うさが違う。
- 仮面の切れ端は、誰の物を落とすか選べる（麗子・担当者）。
- 仕入れ帳を送るかは、ENDING 3でも選べる（送ると、年明けに警察が屋敷に来る余韻）。
- ENDING 3では「深い仲の相手との別れ」の代わりに、残って働く日々の一場面（お嬢様と廊下ですれ違う目配せ、など）を見せる。
- ENDING 3の失敗は新しいバッドエンド（取り調べで見抜かれる）。

## 伏線と回収（主なもの）
麗子の誕生日と番号／赤の電話と運び屋の時刻／伝票・額縁の荷物・夜中の業者＝担当者／地下の帳簿＝客たち／嵐の夜の警報の電源＝停電／白の電気の知識と会社の裏金（客に役員）／青の模写と仮面の絵付け／書斎の油絵具の匂い＝お父様が自ら絵を掛ける／前のメイドの濡れ衣＝取り調べで赤が言い返す／お母様の贈り物の若い男＝麗子の連れ／お嬢様の退学＝客の前で「美術史を学ぶ娘」と紹介される／雫の日記の蔵印＝本物の証拠／巡回員＝舞踏会の警備／雫の知人＝仕出し屋。

## 仮面と VRM
- 仮面はゲームの中で作る（頭の骨に付けるベネチア風の半仮面。人物ごとに色と飾り。仮面外しの動き、切れ端、仮面付きの顔アイコン）。仮面姿の VRM は作らない。
- 新しい VRM：reiko・daughter3（お嬢様のドレス）・dealer（担当者。`tools/vrm_fix_tie.py` で蝶ネクタイを消し、ネクタイをベストの中へ）・caterer（仕出し屋）・一般客4体（`assets/vrm/guest/`。`tools/vrm_guest.py` で作る軽い版。複製して10〜20人に見せる）。
- 舞踏会のメモリ対策：客は複製（形と画像を共有）、その場にいない人のモデルは手放す。

## 音楽（案1で決定）
- 著作権の切れた曲の、自由に使える演奏（パブリックドメイン／CC0）を使う。ファイルは用意してもらう（この作業環境からは外のサイトに接続できない）。
- 場面：タイトル／昼の執事パート／夜／イブの舞踏会／ダンス（ワルツ）／決行／エンディング（結末ごと）。効果音（足音・扉・警報・停電・仮面が外れる音）も入れる。
- 設定に音量（音楽・効果音）。スマホは最初のタップで鳴らし始める。
